# Logo

`jev-logo.png` is a generated question-and-answer logo for this unofficial Jev client.
It combines an adapted Go Gopher with an original Jev assistant character.

The [Go Gopher was designed by Renee French](https://go.dev/doc/gopher/README)
and is licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The composition and pose were adapted using the built-in imagegen tool.
